factory: a pull request whose diff adds or widens a command outside the sandbox is the owner's under every shard and every decision, by the new authority rule `unsandboxed_command`, whatever file carries it: `excludedCommands`, `allowUnsandboxedCommands` other than `false`, `dangerouslyDisableSandbox`, an import of `child_process` or a bare spawn call, read from the pull request's patches. A file with added lines GitHub gives no patch for is denied as unread. Tests and `*.md` files are not read. It is a text match that closes these forms, not the whole class; `architecture/security-invariants.md` lists what it does not see.
