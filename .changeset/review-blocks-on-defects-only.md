'mikoshi-construct': patch
---

Only a defect of code, tests or the contract makes a review verdict changes: a finding only on the description of the pull request, the changeset or the prose of the card is advice the reviewer repeats in `advice`, and a verdict whose findings are all advice is recorded as pass with them kept. Every review round, the re-review included, diffs the head from the merge-base of main, so a file the head brought in by merging main is no longer read as the card's change.
