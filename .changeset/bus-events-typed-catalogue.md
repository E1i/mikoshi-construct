Every bus event type now declares its payload keys in one catalogue, `EVENT_PAYLOADS` in `scripts/core/events.ts`, and `contract/factory.json` measures each event against its writers instead of guessing. A payload key is read from the syntax, from the call site of a writing helper, or through the TypeScript checker for a spread or typed value. A writer that writes an undeclared key is refused, and an event stays incomplete while any writer spreads a payload whose keys no type bounds. Open payloads (`window.request`, `ghost.line`, a re-spread `card.admitted`) pass `declaredPayload`, which refuses an undeclared key at write time. The reducer folds only catalogued types.

The bus section now lists 112 event types, all complete, where it listed 109 with 52 incomplete and 4 written outside the catalogue. Seven types entered: `decision.expired`, `decisions.projected`, `role.to_owner` and `worker.retiring` (the four outside), plus `role.raise_failed`, `main.advanced` and `netwatch.skipped`, which were written or folded but had no constant there. Four left, because they are stop or wait reasons (`payload.reason` values of `card.stopped` and `card.waiting`), not event types: `question.agent`, `question.owner`, `ladder.approval` and `witness.downgrade`. Their constants stay exported. The card names `witness.downgrade` among the core events, but no code writes it as a type, so it is not one. Stored events are not rewritten and no payload changes for its readers, so `busVersion` stays 2.
