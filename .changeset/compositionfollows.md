A composition record and the document its `doc` field names now follow a card whose touches reach a path one of that model's nodes names, so a card changing that code no longer stops on an owner question to widen its touches. The fence reads the models as they stand at the base, and every other guarded path still refuses to follow. A pull request carrying a composition record stays R1 for merge policy and review. The rule applies only where the factory runs from a checkout: an installed package ships no composition reader, so there a composition record stays outside the touches and the fence refuses it as before.
