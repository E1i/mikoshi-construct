The launch scheduler treats a card's touches as the resources it holds. An open pull request whose diff the bus has recorded holds only the files of that diff and no longer holds its lane. A card held for the owner gives way to a card of higher priority. A generated contract file (`contract/*.json`, or any generated row whatever its `rebuiltOnUpdate`) is no overlap. Every overlap judge reads the one `sharedAppendFiles` declaration, which now lists `scripts/core/events.ts`.

A card that can start and has not started now names its holder on the board: an overlap names the pull request or session and the path, a lane names the card ahead, a `who: window` card names `who: window` or its unclear field. A card with no holder found reads red, never the residual "occupied slots".

The intake volume seam no longer measures reading against a fixed 100k. It uses a share of the context line for the card's size (the line, less about 35k for the session start and 40% of the line for reasoning). An M card that passes its budget is told to raise its size to L or to take the cut.
