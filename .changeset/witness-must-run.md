intake: a witness that cannot run is marked unclear before launch, at intake and at `--admit` alike, with the witness and the reason named. Three new reasons sit beside the unresolved command, `origin/main` and `bash -n` ones: a witness written as prose (a `→` step chain, output "in the PR body", a step done by hand), a witness whose command names a path outside the repository (`~/…`, `$HOME`, an absolute path not under it; `/dev/` stays allowed), and a witness that reads nothing the tree under test can change (no repository path and no `pnpm`, `node`, `git` or similar tool that reads the tree), so its result cannot depend on the head.
