intake: a witness that cannot run is marked unclear before launch, at intake and at `--admit` alike, with the witness and the reason named. Three new reasons sit beside the unresolved command, `origin/main` and `bash -n` ones: a witness written as prose (a `→` step chain, output "in the PR body", a step done by hand), a witness whose command names a path outside the worktree it runs in (`~/…`, `$HOME`, or any absolute path, the checkout intake reads included; `/dev/`, a `-t` test-name pattern and an output redirect target are not read paths), and a witness that reads nothing the tree under test can change (no repository path, and no `pnpm`, `node`, `git` or similar tool beyond `--version` or `--help`), so its result cannot depend on the head.
