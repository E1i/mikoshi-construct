`construct atlas`: the header of the map and the docs pages names the repository and describes it, and says where each came from. The name is the `name` in `package.json`, else the first `#` heading of the README, else the folder name, else "unknown repo"; the description is the `description` in `package.json`, else the first paragraph of the README, else nothing. Before, the header showed only the folder name.
