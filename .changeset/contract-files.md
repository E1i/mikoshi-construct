`contract/factory.json` now has a `files` section: every file and table the factory keeps in the home directory or under `.construct/` gets an entry naming its owner module and its single source. The entries are generated by `scripts/contract/factory/files.ts`. Generation fails, and so does CI, when a file has no entry or when a file has two writer modules. `lane.json` and `owner-decisions.md` are recorded as derived views: the first of the `lane.assigned` event, the second of the `decisions` table. Each is owned by the one writer of its source.
