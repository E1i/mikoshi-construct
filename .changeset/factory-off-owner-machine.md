`construct board`: the board reads the bus of the repository `--dir` names, at `~/.construct/<owner>--<repo>/bus.db`, where `<owner>/<repo>` comes from that repository's git remote (`origin` first; a repository without a remote gets a local id of its own). A foreign repository no longer shows another repository's lanes and cards. A machine-wide `~/.construct/bus.db` from before is still read until the repository has a bus of its own; `CONSTRUCT_BUS_DB` still names a bus outright. The bus that serves a repository keeps its database, logs and switch file in that same `~/.construct/<owner>--<repo>/`. The launchd job `scripts/bus/launchd/dev.mikoshi.bus.plist` no longer starts in a fixed checkout and no longer passes a `GH_TOKEN` for a fixed account: gh answers with its active account, and the job runs in the checkout `CONSTRUCT_FACTORY_DIR` names. Set it once with `launchctl setenv CONSTRUCT_FACTORY_DIR <checkout>` before reloading the job; without it the job exits 1 and `~/.construct/dev.mikoshi.bus.log` names the missing variable.
