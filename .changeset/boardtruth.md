`construct board` groups the backlog by the parking lane a card was admitted to or moved to with `intake --move`, not by the launch slot the bus gave it. The launch slot is kept apart as `slot-N` and is never named a lane, and empty `lane-1…N` headings are no longer printed. Every wait under "waits for you" now ends with a ready command and who runs it: the owner runs `gh pr merge` for a merge wait and `pnpm decisions:add` for a decision, and the window runs the `pnpm intake` and `pnpm bus:request` commands a wait names. Each open plan shows a text progress bar. When the bus holds live cards but no open plan, the board prints `plan not registered` with the command that registers one, and an empty flow names the command that admits a card. The bus also closes a wait that asked the window to amend a card as soon as that card is admitted again. On `board.html`, the BUS LIVE indicator reads the factory's liveness from the window heartbeat: a fresh heartbeat shows `bus live`, and none or a stale one shows `bus offline` in red. The header version is read when the page is rendered, so it is the version of the construct that runs the board. A service tile's ctx and spent readings wrap below the bar when the tile is narrow, instead of being cut off.
