`pnpm decisions:add --card #N --creates <path>` adds a file the owner's decision requires to the card's touches before the decision is requested, so the card does not stop on a touch outside its declaration. A refused witness downgrade at intake prints the ready `pnpm decisions:add` command with the exact phrase intake accepts, and intake now accepts a card-bound decision that names the card, the witness ids and the word «понижение» in any order. `scripts/ci/sandbox-failing.jsonl` is a shared append file, so cards that append to it no longer wait for each other.
