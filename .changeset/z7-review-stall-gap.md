The law registry stops counting a review session as witnessed alive when no witness runs the review node. The registry gains the `supervisor` site, `scripts/supervisor/stalled-sessions.ts`, with a cell for every law; its Z7 cell is witnessed by the case #1792 settled: a live review session whose only stale signal is the context reading is not sent SIGTERM. A law cell is now green only when its witness calls a function of the site's own module, measured by V8 coverage during the run. A gap now holds only while the card it names is open: the law-sites suite rejects a cell whose gap names a merged or closed card, so no cell names #1777 or #1792. The 32 Z3–Z6 cells that already named merged cards on main (#1672, #1754, #1764, #1767) stay pinned in a list that can only shrink, until a card that the window opens re-points them.
