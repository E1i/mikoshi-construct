factory: `construct-factory` in a repository other than the factory's own checkout starts over that repository's bus, `~/.construct/<repo-id>/bus.db`, even before that bus exists and while another factory runs over `~/.construct/bus.db`; until now it fell back to the machine bus, found the other factory's processes, start locks and pid files there, and started nothing. Every factory process now carries its bus as `--bus <absolute path>` on its command line, and a process counts as already running only when that argument names the same bus; the bus is no longer read from another process's environment, which `ps` does not show on macOS. A review worker's pid file is honoured only for a worker of that bus, a review worker's pid file is honoured only for a worker of that bus, and the command exits non-zero when it started nothing for its bus and found nothing proven to run over it. A running process whose bus cannot be read is still left alone and named, but no longer counts as this bus's factory being up.
