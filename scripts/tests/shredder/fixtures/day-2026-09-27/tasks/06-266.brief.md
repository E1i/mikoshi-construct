/implement The CLI refuses an unknown flag and an unknown value of an enumerable flag before doing anything, naming the flag, the value and the allowed values (#266).

Effort: medium — the recorded surface gains the allowed values of each enumerable flag (contract/surface.json via `pnpm contract:update`, and the shape of a flag in scripts/contract/surface.ts), and every command's parsing changes at the composition root; the design is written here.

Design:
- Enumerable flags are declared with citty's own enum type (citty 0.2.2: type 'enum' with options; citty refuses a value outside them with a CLIError naming the flag, the value and the options, and runMain exits 1). Their options come from the constants that already hold them, never restated: init --preset from PRESET_IDS, init --ai and attach --ai from the AI targets (claude, cursor, both — attach keeps its own refusal for cursor and both, so its options list all three), init --review from the review providers (claude, none), mutate judge --format from REPORT_FORMATS. The hand-written parsers parsePreset / parseAi / parseReview in src/commands/init.ts stay only where the value can also come from the record or a prompt; a value from the command line is already checked by citty. The `as ReportFormat` cast in src/program.ts goes.
- scripts/contract/surface.ts records a flag's options: flagsOf writes type and alias as today, and options for an enum flag. The shape of a flag changes, so SURFACE_VERSION goes from 2 to 3, and bump.ts compares against the tag the way decision 0030 D2 already does when the tag's surfaceVersion differs. contract/surface.json only through `pnpm contract:update`; the changeset level is the one `pnpm contract:bump` requires.
- Unknown flags: one small module (for example src/known-flags.ts) takes a command's declared args and the parsed args citty returns, and names every parsed key that is neither a declared flag, one of its aliases, its kebab-case spelling, a --no- negation of a declared boolean, nor citty's own built-ins; src/program.ts applies it to every command and subcommand at one place (a wrapper around defineCommand or a shared setup), before the command's run, and throws citty's CLIError naming the flag, so runMain prints the usage and the message on stderr and exits 1. Nothing is read or written before the check.
- Every new behaviour ships its test in tests/ in the same change: the unknown-flag module (unknown flag named; alias, kebab spelling and --no- negation accepted), the enum refusal for each enumerable flag through the CLI, the surface recording options; each new test is red on the base and green after. The gate does not check this yet (#269), so the implementer must.
- Every user-facing string that is ours lives in src/ui/lore.ts with its PLAIN_LORE counterpart; citty's own EARG message is citty's.
