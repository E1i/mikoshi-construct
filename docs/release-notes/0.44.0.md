# 0.44.0 — the factory ships in the package (beta)

0.44 puts the factory into the published package. Until now the bus, the shifts, the witness and the
review ran only from a checkout of this repository. From 0.44 they are built into `dist/scripts/**`
and start from two new bins, `construct-factory` and `construct-intake`, in any repository a
construct was materialized into or attached to.

The factory is **beta**. That is our own label, and it stays until the factory has run a full day
unattended. A fresh factory starts in WINDOW mode: launch, witness, review and answer run live, and
merge runs in shadow, so a human merges every pull request. Read
[Known limitations](#known-limitations) before you attach the factory to a repository that has a CI
of its own.

## If you are upgrading, do this first

1. **Upgrade Node to 22.13.0 or later before you upgrade the CLI.** The minimum was Node 20 and is now
   22.13.0.
2. **Upgrade every `construct` that reads your `construct.model.json` before you write it with 0.44.**
   0.44 writes the Engram as `modelVersion` 6. A 0.43 or older build that meets that file refuses it as
   written by a later build. That refusal is correct, but it looks like breakage. The same holds for
   the attach record, now `recordVersion` 4: detach with a 0.44 build.
3. **Drop `--journal`.** `construct intake` and `construct mutate judge` no longer take it, and intake
   no longer falls back to `~/.construct/handoff/ghosts.jsonl`; the bus is what they read.
4. **Use `construct-intake` beside a factory.** Where a factory bus exists, plain `construct intake`
   writes nothing, names `construct-intake` and exits 1, and so do `--admit` and `--move` in a run with
   no bus wired. Nothing is lost: the bus-wired intake is the one that records the card.
5. **Read `cheap.bus`, not `cheap.windowJournal`,** in `construct cost --json`. Cost now reads closed
   cheap cards from the bus database (`CONSTRUCT_BUS_DB`, default `~/.construct/bus.db`).
6. **Expect a large diff on the first `construct atlas` in a repository `init` made.** The Engram's
   `mechanics` no longer go into the tracked `construct.model.json`; they go to the gitignored
   `.construct/mechanics.json`, so the first run removes them from the tracked file.
7. **Run `construct attach` or `construct init` before `construct atlas`.** Atlas now refuses, with
   exit 1, a repository that has neither a `construct.json` nor an attach record.
8. **Stop the factory before you detach.** Detach refuses while a LaunchAgents plist still names the
   factory directory.

## Known limitations

- **Attach into a repository whose CI has no job named `required`.** When a construct is attached
  (`attach`, or hijack) to an existing repository with its own CI, and that CI has no job called
  `required`, the bus review never starts: for the bus, CI stays pending. The window, the shifts, the
  witness and a human merge all work. Workaround: add a `required` job to your CI that waits for your
  main jobs, as the CI `construct init` writes already has. A fix is planned for 0.45.

## What a new project gets

- **The generated CI ends with one `required` job** that waits for every other job, so a branch rule
  can require that one check alone.
- **`pnpm run quality` passes in a sandbox without local port binding.** The `/health` tests use
  `light-my-request` instead of `supertest`, and the `composition:*` scripts run as
  `node --import tsx`. A repository generated earlier keeps `supertest` and `tsx` until you change them
  by hand.
- **Tab-window hooks are tracked in the repository** (`scripts/construct/window-hooks.mjs`), merged
  into `.claude/settings.json`, and read the handoff of their own repository.
- **`init` and `attach` ask how many parallel lanes to run** (default 3; `--lanes <count>` skips the
  question).

## The factory

- Each repository gets its own bus, its own owner-decisions file and answers directory, and card
  trees under `<bus>/worktrees/<card>`. `attach` deploys the factory directory beside the repository,
  `~/.construct/<repo id>/`, and `detach` removes it with the Engram.
- Card sessions start with their own `--settings`, the sandbox on, and
  `--setting-sources project,local`: your `~/.claude/settings.json` no longer loads into them.
- `construct say "<words>"` writes an owner word. `--mode ghost-protocol --hours n` needs a
  `ghost-protocol <n>h` owner word first.
- Run `construct-factory` once in each repository to rewrite an agent an earlier version installed.

## Intake and the board

- **Intake** files cards into lanes, turns proposed slices into cards with `depends` taken from the
  import order, puts covering tests on a `Runs:` line instead of into touches, and marks a witness
  unclear when it is prose, names `origin/main` or a path outside the worktree, fails `bash -n`, or
  reads nothing the tree under test can change. A card that touches an R1 path gets decision `owner`.
  A card corrected on admission waits behind a confirmation token (exit 2); a card whose `depends`
  are not merged yet is admitted and waits for them.
- **`construct board`** reads the bus and shows three screens — Flow, Backlog with a swimlane per
  lane, and Services — with each card's stage, each queue's slots as `used/total`, and every owner wait
  with the command that answers it.

## Everything else in 0.44

- **The Atlas is an interactive map.** It opens on the contours the repository declares, at most 30
  nodes at first, with filters, search and sorting, and shows entry points (package scripts, workflow
  steps, Claude Code hooks). The page has a new look and a dark and a light theme; it still fetches
  nothing. Source links open on the GitHub or GitLab remote, or in an editor with
  `"atlas": { "open": "vscode" }`. `init` writes a `/construct-atlas` skill.
- **Attach accepts a repository that already carries its own construct.**
- **The `/implement` ladder** refuses a brief whose Acceptance or Invariants items were not split
  where the author meant, matches a criterion written as a list item without its marker, and stops on
  its first rung as `base unverified` when no witness names a criterion, instead of climbing.
